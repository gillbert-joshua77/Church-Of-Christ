# Prototype

This folder contains **old visual reference files** only.

| File                      | Purpose                                  |
| ------------------------- | ---------------------------------------- |
| `html/church-prototype.html`       | Early visual mock-up of the website |
| `html/church-prototype-fixed.html` | Fixed/refined version of the mock-up |

These files are **not** part of the production implementation and are **not**
imported by the React application in `frontend/`. They are kept purely as a
design reference for the original look-and-feel.

> The production website lives in `frontend/` (React + Vite + Tailwind CSS).
> See the [root README](../README.md) for the current project structure.
