# Assets

This folder is for **original / raw project materials** that are **not**
directly part of the React application.

- `images/` — raw or source images not used by the frontend
- `logo/` — original logo files and design sources
- `reference/` — reference materials, wireframes, sketches, notes

> The production frontend serves its application assets from
> `frontend/src/assets/` (see `frontend/src/assets/images/` for the images
> currently used by the website). Do not duplicate those images here unless
> there is a genuine reason.
