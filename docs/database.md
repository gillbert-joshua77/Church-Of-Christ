# Database

> **Status: Planned.**

There is **no database yet**. The frontend renders static content only.

The database schema will be designed when the backend is implemented. Planned
stack: **PostgreSQL** with **Django ORM**.

Candidate models (not final) based on the planned backend responsibilities:

- Songs / Lyrics
- Videos (metadata)
- Daily Bible verse
- Prayer requests
- Contact messages
- Church content (news, events, announcements)
- Admin users / authentication
- Media

The schema, migrations, and model relationships will be documented here once
designed.
