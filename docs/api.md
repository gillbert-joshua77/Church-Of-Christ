# API

> **Status: Planned.**

There is **no API yet**. The frontend currently renders static, bundled
content.

API design will be added here when the backend is implemented. Planned backend
topics (see [`backend/README.md`](../backend/README.md)) that will shape the
API:

- Songs / Lyrics
- Videos metadata
- Daily Bible verse
- Prayer requests
- Contact messages
- Church content
- Admin authentication
- Media management

Endpoints, request/response shapes, and authentication will be documented in
this file once designed.
