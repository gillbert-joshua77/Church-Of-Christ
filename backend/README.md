# Backend

> **Status: Planned — not yet implemented.**

The backend will be built with:

- **Django** — web framework
- **Django REST Framework** — REST API
- **PostgreSQL** — relational database

## Planned responsibilities

Future backend features may include:

- Songs / Lyrics management
- Videos metadata
- Daily Bible verse configuration (if needed)
- Prayer requests
- Contact messages
- Church content management
- Admin authentication
- Media management

None of these are implemented yet. This folder intentionally contains only
this README until the backend is designed and built. See
[`docs/api.md`](../docs/api.md) and [`docs/database.md`](../docs/database.md)
for the planned API and database notes.
